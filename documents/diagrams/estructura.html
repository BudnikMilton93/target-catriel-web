Estructura del proyecto

Carpetas de primer y segundo nivel. Frontend en JSX (sin TS), backend TypeScript bajo api/.

src/
Frontend — React 19 + Vite, sin TypeScript
pages/
Home, Login, Clases, Viajes, Admin, Alumnos, Contacto, SobreNosotros, SeleccionarPanel 9 páginas
components/dashboard/<rol>/
Un panel por rol: admin, alumno, profesor, marketing
components/{home,clases,viajes,profesor,admin,layout,shared}/
Componentes de UI agrupados por sección o reutilizables
context/AuthContext.jsx
Auth mockeada — cualquier password funciona, no hay JWT real acá
hooks/
useAlumno, useProfessor, useMarketing — lógica de datos por rol
services/
api.js, contentService.js — llamadas HTTP hacia api/
styles/
CSS con variables custom (theming de marca)
api/
Backend — funciones serverless estilo Vercel, TypeScript
_lib/
auth.ts, db.ts, response.ts, roles.ts, types.ts — compartido por todos los endpoints
admin/
usuarios/, reportes/
profesor/
bloques/, modulos/, contenidos/, alumnos/, respuestas/
alumno/
bloques/, modulos/, respuestas/, asistencias/
marketing/
noticias/, viajes/, galeria/, sobre-nosotros/
prisma/
Esquema y semilla de datos
schema.prisma
18 modelos — ver diagrama de Arquitectura
migrations/
init, add_registro_auditoria
seed.ts
Usuarios de prueba (uno por rol)
documents/
Roadmaps por rol + arquitectura + testing — revisar antes de tocar un área
ARQUITECTURA.md
Modelo de datos y decisiones técnicas
TESTING.md
Guía funcional + referencia de endpoints (cURL)
ROADMAP_{PROFESOR,ALUMNO,ADMINISTRADOR,MARKETING}.md
Pendientes por rol
e2e/
Specs de Playwright — hoy solo auth.spec.ts
scripts/
dev-api-server.ts — servidor local para api/ en desarrollo
Conteos y rutas verificados contra el repo el 2026-08-26 — pueden desactualizarse a medida que el proyecto crece.
